# cana-carbono
Proposta de investigação sobre hard carbon derivado de bagaço de cana-de-açúcar para baterias de íon-sódio

## Resumo do Piloto
A fase piloto propõe um teste mínimo e controlado (sem edição genômica inicial) utilizando:
* Um painel de germoplasma (cana convencional × cana-energia)
* Duas janelas de colheita diferentes
* Uma rota única e congelada de processamento (pré-tratamento, pirólise e ensaio eletroquímico)

O objetivo é isolar o "sinal do genótipo". Se a variedade da planta alterar de forma reproduzível propriedades como capacidade reversível e eficiência coulômbica inicial (ICE), alvos de edição genética (como os genes *SoLIM* ou *F5H*) ganharão justificativa experimental sólida.
